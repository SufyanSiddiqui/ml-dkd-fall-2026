# Mid evaluation report

The report source is the LaTeX file:

- `mid_evaluation_report.tex` — literature review and exploratory data analysis
- `mid_evaluation_report.html` — the same report as a web page
- `mid_evaluation_report.txt` — the same report as plain text
- `Mid_Evaluation_Report.pdf` — a reading copy printed from the HTML

This Mac does not have a LaTeX compiler installed. Open the `.tex` file in Overleaf, or run `pdflatex mid_evaluation_report.tex` twice, to produce the PDF from LaTeX. The figures are in `figures/`.
